# ساخت نسخهٔ ویندوز و اجرای برنامه

سه روش اجرا وجود دارد: **نسخهٔ وب (مرورگر)**، **نسخهٔ دسکتاپ (Electron)** و **نسخهٔ نصب‌شدنی ویندوز**.

---

## ۱. پیش‌نیازها

| ابزار | نسخهٔ حداقل |
|---|---|
| Node.js | ۱۸ (توصیه: ۲۰ یا ۲۲) |
| npm | ۹ |
| ویندوز | ۱۰ یا ۱۱ (برای ساخت نصب‌کننده) |

---

## ۲. نصب وابستگی‌ها

```bash
git clone https://github.com/gase99/Max.git
cd Max
npm install --legacy-peer-deps
```

> `--legacy-peer-deps` لازم است چون `@testing-library/jest-dom` نسخهٔ جدیدتر React را هم پیشنهاد می‌دهد.
> این پرچم فقط روی حل وابستگی‌های محیط تست اثر دارد و روی کد برنامه اثری ندارد.

---

## ۳. اجرای نسخهٔ وب (توسعه)

```bash
npm run dev
```

آدرس: `http://localhost:5173`

برای ساخت نسخهٔ نهایی و اجرای آن:

```bash
npm run build
npm run preview
```

خروجی در `apps/web/dist` قرار می‌گیرد و یک بستهٔ کاملاً استاتیک است — می‌توان آن را روی هر وب‌سرور
داخلی یا حتی از روی فایل باز کرد. Service Worker باعث می‌شود بعد از اولین بارگذاری، برنامه
**بدون اینترنت** هم باز شود.

---

## ۴. اجرای نسخهٔ دسکتاپ (Electron)

```bash
cd apps/desktop
npm install
npm start
```

`npm start` ابتدا بستهٔ وب را می‌سازد، آن را در `apps/desktop/app/` کپی می‌کند و پنجرهٔ دسکتاپ را
باز می‌کند.

### ویژگی‌های امنیتی پوستهٔ دسکتاپ

| تنظیم | مقدار |
|---|---|
| `nodeIntegration` | `false` |
| `contextIsolation` | `true` |
| `sandbox` | `true` |
| `preload` | فقط نسخهٔ Electron را افشا می‌کند |
| بارگذاری محتوا | فقط فایل محلی؛ هیچ آدرس راه‌دوری بارگذاری نمی‌شود |
| لینک‌های خارجی | با مرورگر سیستم باز می‌شوند، نه داخل برنامه |

---

## ۵. ساخت نصب‌کنندهٔ ویندوز

```bash
cd apps/desktop
npm run dist:win
```

خروجی‌ها در `apps/desktop/release/`:

| فایل | نوع |
|---|---|
| `Cabinet Analysis Pro Setup <version>.exe` | نصب‌کنندهٔ NSIS (x64) |
| `Cabinet Analysis Pro <version>.exe` | نسخهٔ Portable بدون نصب |

برای ساخت، در ویندوز نیازی به ابزار اضافی نیست. اگر در لینوکس می‌سازید، به `wine` نیاز دارید
(electron-builder برای ساخت NSIS از wine استفاده می‌کند).

### آیکون

فایل `apps/desktop/build/icon.ico` (۲۵۶×۲۵۶) را قرار دهید. بدون آیکون هم ساخت انجام می‌شود و
ویندوز آیکون پیش‌فرض Electron را نشان می‌دهد.

## ۶. اجرای تست‌ها

```bash
npm run test          # موتور محاسبه + تست طلایی اکسل (۹۲ تست)
npm run test:web      # رابط کاربری در jsdom (۱۸ تست)
npm run test:all      # هر دو
```

## ۷. ساختار مخزن

```
Max/
├─ packages/engine/          موتور محاسبه — خالص TypeScript، بدون UI
│  ├─ src/legacy/            فرمول‌های وارثی اکسل (صحت‌سنجی‌شده)
│  ├─ src/optimize/          چیدمان ورق (guillotine)
│  ├─ src/cuttingList.ts     ساخت لیست برش
│  ├─ src/pricing.ts         بهای تمام‌شده
│  └─ test/fixtures/         دادهٔ طلایی از اکسل
├─ apps/web/                 رابط کاربری React + Vite
│  ├─ src/screens/           ۱۲ صفحه
│  └─ test/                  تست‌های DOM
├─ apps/desktop/             پوستهٔ Electron + بسته‌بندی ویندوز
├─ docs/                     مستندات فارسی
├─ audit/                    خروجی خام ممیزی اکسل
└─ tools/                    اسکریپت‌های استخراج و تولید دادهٔ تست
```

## ۸. عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `npm install` با خطای peer dependency | از `npm install --legacy-peer-deps` استفاده کنید |
| صفحهٔ سفید در نسخهٔ دسکتاپ | `npm run build:web` را اجرا کنید؛ فایل `app/index.html` باید وجود داشته باشد |
| `electron-builder` روی لینوکس خطا می‌دهد | `wine` را نصب کنید یا در ویندوز بسازید |
| داده‌ها پس از به‌روزرسانی از بین رفتند | پشتیبان JSON (صفحهٔ پروژه‌ها) را بازگردانی کنید |
| چاپ درست نیست | در دیالوگ چاپ، پس‌زمینه‌ها را غیرفعال و مقیاس را روی ۱۰۰٪ بگذارید |
