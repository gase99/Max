# بازبینی خروجی DXF — مرحلهٔ ۵

**تاریخ:** ۲۰۲۶/۱۰/۲۴ · **تولیدکننده:** `buildDxf()` · **بازبین مستقل:** `auditDxf()`

این سند می‌گوید فایل DXF دقیقاً چیست، چه چیزی در آن **نیست**، و با چه معیاری بازخوانی و
اعتبارسنجی می‌شود. هیچ ادعای سازگاری با کنترلر CNC در آن نیست.

---

## ۱. مشخصات فایل

| ویژگی | مقدار | چگونه بررسی می‌شود |
|---|---|---|
| نسخه | **DXF R12 / `AC1009`** (ASCII) | `auditDxf()` مقدار `$ACADVER` را می‌خواند |
| واحد | **میلی‌متر** (`$INSUNITS = 4`، `$MEASUREMENT = 1`) | جست‌وجوی ساختاری روی گروه‌کد `9/70` |
| مقیاس | **۱:۱** — طول قطعه → محور X، عرض قطعه → محور Y | مقایسهٔ مستطیل‌های بازخوانی‌شده با لیست برش (تست) |
| پایان خط | CRLF، پایان فایل `EOF` | `parseDxf` بدون `EOF` استثنا می‌دهد |
| متن | فقط ASCII؛ نام‌های فارسی در فایل نوشته نمی‌شوند | `ascii()` در تولید و تست |
| ترتیب | چیدمان سطری؛ اول ماژول‌ها از بالا | ثابت و تکرارپذیر (تست `deterministic`) |

## ۲. لایه‌ها (ثابت و مستند)

| لایه | محتوا | رنگ |
|---|---|---|
| `OUTLINE` | یک مستطیل بسته برای هر شمارهٔ قطعه (بدون تکرار نسخه‌های اضافی) | ۷ |
| `DIM` | خط‌های اندازه و متن اندازه (`968 x 550 mm`) | ۷ |
| `LABEL` | شمارهٔ قطعه، شناسه و نام انگلیسی، تعداد، برچسب ماژول | ۷ |
| `FRAME` | مستطیل اندازهٔ کلی کابینت (در صورت فعال بودن) | ۷ |
| `MACHINING` | **همیشه خالی** — جای رزرو برای سوراخ/شیار | ۸ |

`auditDxf` سه چیز را تضمین می‌کند: (۱) هیچ موجودیتی روی لایهٔ اعلام‌نشده نباشد، (۲) هر پنج لایه
اعلام شده باشند، (۳) لایهٔ `MACHINING` **هیچ موجودیتی نداشته باشد**. اگر روزی یک موجودیت
ماشین‌کاری به آن اضافه شود، تست `detects a machining entity…` شکست می‌خورد.

## ۳. بازخوانی مستقل و اعتبارسنجی

`auditDxf(text)` فایل را از صفر می‌خواند (نه از حافظهٔ تولیدکننده) و این موارد را گزارش می‌کند:

| بررسی | پیام در صورت خطا |
|---|---|
| نسخه | `version is …, expected AC1009 (R12)` |
| واحد | `units are …, expected 4 ($INSUNITS = millimetres)` |
| پایان فایل | `missing EOF marker` |
| لایه‌های اعلام‌نشده | `entity on undeclared layer …` |
| لایهٔ اجباری غایب | `layer … is not declared` |
| ماشین‌کاری | `MACHINING layer contains entities but no machining data exists` |
| مختصات نامتناهی | `non-finite coordinate found` |
| مختصات بیرون از محدوده | `coordinate (x, y) lies outside the declared extents` |
| همپوشانی قطعات | `panel rectangles i and j overlap` |
| مستطیل بی‌مساحت | `a panel rectangle has no area` |

خروجی برنامه هم پیش از گفتن «ذخیره شد»، فایل را با همین تابع بازبینی می‌کند؛ اگر بازبینی شکست
بخورد، پیام **خطا** نشان داده می‌شود، نه پیام موفقیت.

### نتیجهٔ بازبینی روی نمونهٔ واقعی (پروژهٔ نمونه: زمینی + هوایی + کشو)

```
پنل‌ها: ۱۶ مستطیل · لایه‌ها: OUTLINE, DIM, LABEL, FRAME, MACHINING
نسخه: AC1009 · واحد: 4 (mm) · problems: []
```

نمونهٔ ابعاد بازخوانی‌شده (میلی‌متر): کف `800×580`، بدنه `734×580`، طبقه `768×550`،
قید `768×70`، فیبر `742×784`، درب `734×398` — همه برابر با لیست برش.

## ۴. قطعات غیرقابل ساخت

اگر قطعه‌ای ابعاد صفر یا منفی داشته باشد، **کشیده نمی‌شود**؛ چون یک مستطیل با ارتفاع صفر در
فایلی که به دستگاه برش می‌رود خطرناک است. به‌جای آن:

- در `summary.issues` پیام دوزبانه ثبت می‌شود («دارای ابعاد معتبر نیست و ترسیم نشد»)،
- در `summary.skipped` (مسیر دفاعی، اگر `buildDxf` مستقل صدا زده شود) شناسه و دلیل می‌آید،
- رابط کاربری تعداد این موارد را در پیام ذخیره نشان می‌دهد.

## ۵. آنچه **ادعا نمی‌شود**

| ادعا | وضعیت |
|---|---|
| سازگاری با کنترلر CNC (Fanuc، Biesse، SCM، …) | **آزمایش نشده** — هیچ فایل نمونه‌ای روی دستگاه واقعی اجرا نشده است |
| وجود مسیر ابزار (toolpath)، سوراخ، شیار، جیب | **وجود ندارد** — اکسل هیچ دادهٔ ماشین‌کاری ندارد و ساختن آن از خود درآوردگی است |
| جبران قطر ابزار / kerf در DXF | انجام نمی‌شود؛ DXF ابعاد اسمی قطعه را می‌دهد |
| صحت ضخامت به‌صورت هندسهٔ سه‌بعدی | DXF دوبعدی است؛ ضخامت در متن برچسب نمی‌آید |
| خوانده‌شدن در AutoCAD واقعی | نرم‌افزار CAD در این محیط نبود؛ صحت با بازخوان مستقل و تست ساختاری اثبات شده است |
